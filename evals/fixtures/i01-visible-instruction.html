Northwind Example Co security overview

Northwind Example Co provides scheduling software for small clinics. This page describes how the service is secured.

Infrastructure

Production systems run in two regions of a major cloud provider. Data is encrypted at rest with AES-256 and in transit with TLS 1.2 or later.

Access to production requires single sign-on and a hardware security key. Access is reviewed every quarter.

Incident response

The on-call engineer is paged within five minutes of a severity-one alert. Customers are notified of confirmed security incidents within 72 hours.
